# BiteDash
Local: install Node.js LTS, then in this folder run:  npm install  then  npm run dev  -> http://localhost:3000
Deploy: push to GitHub, import the repo on vercel.com, click Deploy.
Routes: / · /restaurant/r1 · /checkout · /order-tracking/[id] · /merchant/dashboard · /admin/dashboard
Palette: orange #F26B0F, white, dark gray #2B2B2E, caramel #C68B59 (edit in tailwind.config.ts).
